# 📸 SafeSafar Application Screenshots

This directory stores real demonstration screenshots for the SafeSafar platform presentation and documentation.

## Required Hackathon Screenshots (Capture these from your device):

1. **`login.png`**: Mobile Auth Screen — Email + 4-digit PIN authentication with email verification notice.
2. **`safe_route.png`**: Safe Route Evaluation — Alternative route corridors (Green / Yellow / Red) displaying safety score (0–100), lighting index, police proximity, and plain-language explanation.
3. **`sos_walk.png`**: SOS & Walk With Me — Live trip guardian telemetry, SOS countdown, and automated alert dispatch.
4. **`report_hazard.png`**: Community Incident Reporting — Categorized hazard logging (lighting, deserted street, harassment) with GeoJSON location mapping.
